================================================================================
                    PRAHARI SYSTEM DEPENDENCIES & REQUIREMENTS
================================================================================

1. Python Version:
   - Python 3.10, 3.11, or 3.12 (64-bit) recommended.

2. Python Packages (installed automatically by PRAHARI_LAUNCHER.exe):
   - ultralytics (YOLOv8 real-time object detection)
   - mediapipe (Real-time Hand tracking & gesture recognition)
   - opencv-python (Computer Vision capture & rendering engine)
   - pyttsx3 (Text-to-speech procedural voice guidance)
   - PyQt6 (Mission Control desktop graphical user interface)
   - numpy (High-performance spatial coordinate calculations)
   - requests (HTTP networking for mobile camera telemetry bridge)

3. Network & Hardware Requirements:
   - Camera: USB Webcam, RTSP IP Camera, or Android Chrome Browser Camera
   - Wi-Fi/LAN: Port 8000 for mobile camera streaming bridge
   - Audio: Speakers / headphones for procedural voice prompts

================================================================================
